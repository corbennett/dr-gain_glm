# Responsive-cell preference comparison: initial results

The full analysis completed under `caffeinate` for all 82 cached sessions with
no failures. It screened 35,576 QC neurons across the same 17 areas. The
independent selection and evaluation procedure, response test, matched contrasts,
and mouse-level inference are described in the [methods](README.md).

## Primary window: 0–100 ms

Responsiveness selection at corrected q ≤ .05 identified **3,900 / 35,170 expert
cells** and **44 / 406 naive cells** using half the trials. Both preference
measures were evaluated exclusively on the other half. The same response-strength
denominator was used for both contrasts.

- **Modality preference is reproducible in all 17 expert areas**, relative to
  the held-out stimulus-label shuffle. This is a population result, not a claim
  that every selected cell is modality selective.
- **Modality preference is stronger than target-versus-nontarget preference in
  15 of 17 areas**, using the paired mouse test and a positive 95% mouse interval.
  CA3 and ORBvl have positive estimates but do not pass the corrected paired test.
- The same **15 areas** pass the primary comparison using unnormalized Hz²,
  so this early-window conclusion is not created by the response normalization.
- **14 areas pass in both trial-split orientations**. ORBvl passes only in the
  reversed orientation; SUB passes only in the primary orientation; CA3 passes
  neither. The reverse analysis selects a separate population and is a
  sensitivity check, not an independent replication.
- Early responsive-cell counts are especially small in CA1 (13), CA3 (11),
  and SUB (10). These results describe the detected subset, not all neurons in
  those areas.

“Stronger” here means a larger average **cross-validated squared preference**,
with sessions averaged within mice and mice equally weighted. The report also
shows signed preference distributions in Hz and relative to response strength,
same-cell absolute-preference scatterplots, and held-out selectivity fractions.
The absolute-value plots are descriptive; the formal comparison avoids the
positive noise bias of squaring or taking absolute values of a single estimate.

## Secondary window: 100–500 ms

The later result differs substantially. Selection identifies 11,276 expert and
157 naive cells in the primary orientation. With response normalization,
**target preference is stronger** in CP, DG, MOp, MOs, MRN, ORBl, SCm, and SSp.
Seven of these also pass the reversed split; DG does not. In unnormalized Hz²,
CP, MOp, MOs, MRN, and SSp pass in both orientations. VISp retains stronger
modality preference in both orientations and on both scales.

This later window can contain action and reward responses. Its selected
population also differs from the early population. Therefore, this comparison
does not establish that individual cells switch from sensory modality encoding
to target encoding, or that the later target preference is purely sensory.

## Naive data and verification

Only one naive mouse has the required anatomical annotations. Its selected-cell
distributions are included, but no across-mouse claim about naive preference
strength or learning is supported.

All **19 analysis tests** passed: nine for this analysis and ten for the earlier
context analysis. The run produced 52 figures. Source hashes, input hashes,
selection counts, report links, and output completeness were checked; the full
run log contains no warnings or errors.
