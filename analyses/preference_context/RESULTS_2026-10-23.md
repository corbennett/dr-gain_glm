# Results: preference type and baseline context encoding

Completed on 2026-10-23 using caffeinate. The direct GLM-linked analysis is in `results/preference_context/glm/`; the separate trial-disjoint check is in `results/preference_context/full/`.

## Main finding

There is no robust evidence here that modality-preferring cells are more likely to encode baseline context than target/nontarget-preferring cells. Some pooled and area-specific estimates favor modality, but no GLM-linked comparison survives its specified across-area correction with mice as the statistical unit. Target-preferring groups are small and support is limited in many areas, so this does not establish equal probabilities.

The primary baseline label matches the notebook: saved GLM context-baseline permutation p < .05. Preference labels come from the previous responsive-cell analysis, with selection and preference measured on different trial halves. Saved GLMs use overlapping trials, so the GLM comparison is retrospective; it is not an independent-trial validation.

## Coverage and limitations

- All 35,170 expert QC cells in the 17 areas have GLM results. The saved table contains 82 expert session files, of which 81 contribute selected-area QC cells. The 406 naive cells have no GLM fits; naive GLM comparisons cannot be made from these saved results.
- The notebook cache was verified against the corrected `/Volumes/programs-2/mindscope` mount: its 82-session set matches the `100926` fits, and four permutation scalars match exactly for sampled units from five session files. The effective full parquet is SHA256 recorded.
- The baseline labels use nominal per-cell p < .05. No cells pass the stricter area-level baseline-cell BH correction. With only 62–81 unique shifts, the permutation p-values have coarse resolution; this stricter sensitivity is uninformative rather than evidence of absent encoding.
- The fully converged subset contains 17,726 QC cells and 3,281 of the 3,900 primary early responsive cells. Both all-fit and converged-only comparisons are saved.
- Target/nontarget status remains confounded with the assigned physical stimulus identities; late preferences may contain action/reward contributions.

## Independent-trial check

The additional analysis completed all 82 cached expert/naive sessions with separate trials for selection, preference, and baseline. Its block-clustered CR2 baseline test with cubic drift detects no cells after correction; effective degrees of freedom are only about 1.18–1.77. The binary probability comparison is therefore inconclusive, and degenerate zero-width intervals are suppressed.

Continuous context effects measured across separate block pairs show no corrected significant early association. One late CP comparison in one reversed orientation favors target-only cells (q=.0297); it is not consistent across the primary split or matching and is not a robust result. This analysis is a different, much more conservative baseline definition and should not replace the notebook labels silently.
